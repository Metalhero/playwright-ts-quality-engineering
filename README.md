# Playwright TypeScript Quality Engineering

Ez a projekt egy Playwright Test és TypeScript alapú automatizált tesztelési példa. A mintatesztek a [playwright.dev](https://playwright.dev/) oldalt ellenőrzik Chromium, Firefox és WebKit böngészőkben.

## Futtatás

```bash
npm install
npx playwright install
npx playwright test
```

A HTML tesztjelentés megnyitása:

```bash
npx playwright show-report
```
